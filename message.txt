# DocAIApp Frontend UI Recreation Prompt

Build a pixel-perfect frontend-only recreation of the provided DocAIApp screenshot using **HTML, CSS, and vanilla JavaScript**.

The application UI should look nearly identical to the reference image while remaining completely dynamic and backend-agnostic.

## Critical Requirements

### DO NOT

* Hardcode document names
* Hardcode chat messages
* Hardcode assistant responses
* Hardcode source citations
* Create backend code
* Create mock APIs
* Use static sample content in the final UI

### DO

* Build only the frontend
* Assume backend APIs already exist
* Render documents from a dynamic documents array
* Render chat history from a dynamic messages array
* Render sources dynamically
* Use loops and templates for all content

---

# Overall Layout

Create a desktop-first enterprise knowledge-base chatbot.

Layout consists of:

* Fixed left sidebar (~320px width)
* Main chat area occupying remaining width
* Full viewport height
* Scrollable content area
* Fixed bottom input bar

The visual appearance should closely match the reference screenshot.
